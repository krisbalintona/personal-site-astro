`vc.el` is Emacs's built-in interface for version control CLI tools. With respect to Git, `magit` has for several years now been the most favored (with respect to popularity) Git<FootnoteRef num="1" /> interface. `magit` is frequently considered a killer-feature&mdash;an irreplaceable feature unique to Emacs.

That's probably true. But also: I believe there are certain advantages to `vc.el`. It is my preferred tool for most cases, and I have been using it full time ever since discovering the [Jujutsu VCS](https://docs.jj-vcs.dev/latest/) and its companion integration with vc.el, [vc-jj](https://codeberg.org/emacs-jj-vc/vc-jj.el).

<FootnoteSection>
Footnotes
<Footnote num="1" slot="footnotes">
`magit` is an interface for Git, whereas `vc.el` is an interface for other version control tools, albeit older ones, some of which may follow a non-decentralized version control paradigm (read the Emacs Info node `(emacs) Version Control Systems` for more information):

-   CVS
-   Subversion (svn)
-   SCCS
-   CSSC
-   Mercurial (hg)
-   Bazaar (bzr)
-   SRC (src)
</Footnote>
