`vc.el` is Emacs's built-in interface for version control CLI tools. With respect to Git, `magit` has for several years now been the most favored (with respect to popularity) Git<sup><a id="fnr.1" class="footref" href="#fn.1" role="doc-backlink">1</a></sup> interface. At least in the r/emacs subreddit, `magit` is frequently considered a killer-feature&mdash;an irreplaceable feature unique to Emacs.

However, I believe there are still certain advantages to `vc.el`.


# Footnotes

<sup><a id="fn.1" href="#fnr.1">1</a></sup> `magit` is an interface for Git, whereas `vc.el` is an interface for other version control tools, albeit older ones, some of which may follow a non-decentralized version control paradigm (read the Emacs Info node `(emacs) Version Control Systems` for more information):

-   CVS
-   Subversion (svn)
-   SCCS
-   CSSC
-   Mercurial (hg)
-   Bazaar (bzr)
-   SRC (src)
