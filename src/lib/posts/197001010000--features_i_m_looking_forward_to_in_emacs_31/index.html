  • New 'fancy value for flymake-show-diagnostics-at-end-of-line (commit diff)

    Enhanced 'flymake-show-diagnostics-at-end-of-line' The new value 'fancy' allowed for this variable will attempt to layout diagnostics below the affected line using unicode graphics to point to diagnostic locus.

    Note that it works best (i) when the line-spacing is 0 (because of the vertical bars) and (ii) when there aren't many diagnostics per line
